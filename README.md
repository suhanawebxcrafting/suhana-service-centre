# Suhana Service centre

A professional, high-end web application for Suhana Service centre, Virar (E). 
Built with Next.js and Tailwind CSS, featuring Elite Service Cards with interactive floating actions and blurred background imagery.

## Features
- **Elite Service Cards**: Interactive, premium cards with instant WhatsApp/Call actions.
- **Dynamic Directory**: Full listing of 70+ government and digital services.
- **Responsive Design**: Fully optimized for mobile and desktop devices.
- **SEO Ready**: Semantic HTML and optimized metadata.

## Setup
```bash
npm install
npm run dev
```
